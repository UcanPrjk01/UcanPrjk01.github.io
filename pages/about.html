About

A developer hub for Android modules and open-source tools.

Introduction

UcanPrjk01 publishes Android modules, customization work and developer tools. The code lives on GitHub, and this site collects downloads, documentation and release notes in one place.

Philosophy

Releases should be easy to inspect and easy to verify. That means public source, a changelog for every version, honest compatibility notes, and SHA-256 checksums next to downloads.

Technical interests

  • Magisk, KernelSU and APatch modules
  • Android customization and system tweaks
  • Kernel and ROM related tooling
  • Developer tools and scripts

Open-source goals

Keep projects readable, documented and reproducible, and make it simple for others to report problems or contribute fixes.
